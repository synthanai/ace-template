# The Intent Dashboard
## Anatomy of Execution (ARC)

You have 12 supercars in your garage. Do not try to drive them all at once. Find the human friction point you are experiencing right now, and execute the corresponding workflow.

---

### 1. AWARENESS (The Input Layer)
*When you need to map the territory.*

| I need to... | Execute | What it does (The Engine Gears) |
| :--- | :--- | :--- |
| **Absorb an external framework quickly** | `AWARENESS/steal.md` | Scan → Translate → Evaluate → Abstract → Leverage |
| **Recall my own past decisions** | `AWARENESS/remind.md` | Retrieve → Extract → Map → Integrate → Navigate → Deploy |
| **Interrogate a complex system** | `AWARENESS/probe.md` | Parse → Reveal → Observe → Break → Extract |
| **Understand a new concept deeply** | `AWARENESS/learn.md` | Log → Extract → Assimilate → Reflect → Normalize |

---

### 2. REASONING (The Processing Layer)

| I need to... | Execute | What it does (The Engine Gears) |
| :--- | :--- | :--- |

| **Stress-test a fragile idea** | `REASONING/sparkit.md` | Scope → Populate → Announce → Rumble → Knit → Interrogate → Transmit |
| **Collate scattered evidence** | `REASONING/gather.md` | Group → Align → Track → Harmonize → Evaluate → Resolve |
| **Choose between two difficult paths** | `REASONING/compare.md` | Calibrate → Observe → Map → Polarize → Analyze |
